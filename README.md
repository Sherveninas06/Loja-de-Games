# 🎮 Loja de Jogos em Python

Sistema de loja virtual desenvolvido em Python para simular a compra de jogos digitais por categorias.

O projeto permite que o usuário navegue entre diferentes categorias de jogos, adicione produtos ao carrinho, receba descontos automáticos conforme o valor da compra e visualize uma nota fiscal ao final da operação. 

---

## 🚀 Funcionalidades

- Cadastro do nome do cliente
- Catálogo dividido em categorias
- Adição de jogos ao carrinho
- Navegação entre categorias
- Cálculo automático do subtotal
- Aplicação de descontos progressivos
- Emissão de nota fiscal
- Exibição dos jogos comprados
- Cálculo do valor final da compra

---

## 🎯 Categorias Disponíveis

- Ação
- RPG
- Esporte
- Corrida
- Sandbox
- Terror
- Indie

---

## 💰 Regras de Desconto

| Valor da Compra | Desconto |
|----------------|-----------|
| Até R$ 99,99 | Sem desconto |
| De R$ 100,00 a R$ 200,00 | 5% |
| De R$ 200,01 a R$ 400,00 | 10% |
| Acima de R$ 400,00 | 15% |
